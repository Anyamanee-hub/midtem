CHARACTERS THAT STAY — IMAGE FOLDER

ไฟล์ภาพที่หน้าเว็บเรียกใช้:
- hero.jpg      = ภาพพื้นหลังขนาดใหญ่ด้านบน
- card-01.jpg   = ภาพการ์ดที่ 1
- card-02.jpg   = ภาพการ์ดที่ 2
- card-03.jpg   = ภาพการ์ดที่ 3
- card-04.jpg   = ภาพการ์ดที่ 4

วิธีเปลี่ยนภาพ:
1. เปิดโฟลเดอร์ images
2. นำภาพของคุณมาแทนที่ไฟล์เดิม โดยตั้งชื่อไฟล์ให้ตรงกันทุกตัวอักษร
3. แนะนำภาพแนวนอนสำหรับ hero.jpg (ประมาณ 1600x900 px)
4. แนะนำภาพแนวนอนสำหรับ card-01.jpg ถึง card-04.jpg (ประมาณ 700x390 px)
5. อย่าลบหรือย้ายโฟลเดอร์ images เพราะ CSS อ้างอิงตำแหน่งนี้อยู่

ภาพที่ให้มาในโฟลเดอร์นี้เป็นภาพ placeholder เพื่อให้เห็นตำแหน่งที่ต้องเปลี่ยนเท่านั้น
